Undo and redo

  • Undo and Redo buttons beside the preset menu reverse edits made in the 4xD window.
  • Each drag, click, reset, typed value or preset choice is one step. Quick repeated nudges of one control combine into one step.
  • Keyboard: ⌘Z and ⇧⌘Z on Mac, Ctrl+Z and Ctrl+Y on Windows, when a 4xD control has focus. Some DAWs keep these keys for their own undo; the buttons always work.
  • Up to 100 steps. The history is kept while the project is open, including when the plug-in window is closed, but is not saved with the project. Host automation is not recorded.

Band bypass

  • Each band has a Bypass switch. A bypassed band passes clean, without Drive or the distortion curve; its Level and the Output gain still apply.
  • Switching is smoothed over 10 ms, so it doesn’t click, and the four Bypass switches can be automated.
  • Solo a bypassed band to hear it clean and set its Level.
  • With every band bypassed the result is close to the dry input but not identical: there is a gentle cut below 25 Hz and up to about 1 dB of variation near the band edges. Use Wet / Dry 0% for the dry signal.

Compatibility

Projects, presets and automation from earlier versions open unchanged, with every band active. The four bypass parameters are added after the existing ones. With no band bypassed, the audio output is the same as 0.2.2.

Test results

Both installers were built and tested by automated runs on macOS and Windows: 13 test suites on each platform, including new undo/redo and band bypass suites; 360 audio and state comparisons and 32 lifecycle checks on the installed plug-in on both platforms, all of which matched; and install and reinstall checks on both, plus uninstall on Windows.

Beta status

Undo/redo and band bypass have been tried by hand on macOS. Hands-on testing in Bitwig, Live and Cubase is ongoing; this beta is not yet fully verified in those hosts, and the automated results do not establish compatibility with every DAW or system.

Requirements & compatibility

Mac: Apple silicon M1 or later and macOS 13 or later. Windows: Windows 10 or 11 x64 with an x64 DAW. A VST3-compatible host is required. No standalone app, Intel Mac, native Windows ARM, AU or AAX version.
